# Lexumi — Language Learning. Redefined.

Android-застосунок для вивчення мов, побудований з нуля за Clean Architecture.

## Як відкрити проєкт
1. Відкрий Android Studio (Koala/Ladybug або новіше).
2. File → Open → вибери папку `Lexumi`.
3. Дай Gradle синхронізуватись (потрібен доступ до google() і mavenCentral()).
4. Запусти на пристрої/емуляторі з Android 8.0 (API 26) або новіше.

## Стек
- **Kotlin + Jetpack Compose** — UI
- **Hilt** — Dependency Injection
- **Room** — офлайн-база даних (усі мови/розділи/теми/контент зберігаються локально)
- **DataStore** — налаштування користувача та сесія
- **Navigation Compose** — навігація між екранами
- **Media3 (ExoPlayer)** — програвання аудіо-діалогів
- **Coil** — завантаження зображень

## Архітектура (Clean Architecture)
```
data/          — Room entities, DAO, repository-реалізації, DataStore
domain/        — доменні моделі, інтерфейси репозиторіїв, use-case'и (бізнес-логіка)
presentation/  — Compose-екрани + ViewModel по одному пакету на фічу
di/            — Hilt-модулі
```

## Ключова логіка вивчення слів (point 20 сценарію)
`domain/usecase/LearnWordsUseCases.kt` + `AnswerChecker.kt`:
- Рівень 0 (multiple choice) → 5 правильних поспіль підвищують до рівня 1
- Рівень 1 (введення тексту) → 1.0 бала за правильну відповідь, 0.5 за одну помилку в букві (перевірка через відстань Левенштейна), 10 балів = слово вивчено
- Неправильна відповідь на рівні 0 обнуляє серію

## Бренд
- Лого й іконка застосунку — з наданих зображень (оброблені, фон видалено)
- Шрифт заголовків — Marck Script (Google Fonts, OFL-ліцензія), максимально близький до почерку в лого
- Кольори й "бульбашки" на фоні — за наданими мокапами
